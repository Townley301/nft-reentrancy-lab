# Security and Scope

This repository is a local educational lab, not production software.

- It contains deliberately vulnerable contracts.
- It must not be deployed with real assets.
- It contains no public-network configuration, real protocol address, private key, or environment-secret loader.
- Please report accidental additions of live-network configuration or secrets before publishing a fork.

The vulnerable contracts exist only to compare unsafe and safe state-update ordering in an isolated local EVM.
