与 [`CALLBACK-FLOW.md`](CALLBACK-FLOW.md) 同文（中英对照）。

> Lab demonstrator: `HypeBearsCallbackStudent`

## 两层账本

- Token ledger: `ownerOf` / `balanceOf`（`_safeMint` 内、回调前已更新）
- App ledger: `addressMinted`（若写在 `_safeMint` 之后，回调窗口里仍为旧值）

## Vulnerable

`检查 → _safeMint（回调）→ 晚写 addressMinted`

学习点 (a): 第一次回调时 `addressMinted == false`（见 `test/hypebears-callback-flow.ts`）

## msg.sender (b)

- 钩子内 `msg.sender` = NFT 合约
- `mintNFT` 的 `msg.sender` = Student
- 本 lab 的 `operator` = Student

## Fixed CEI (c)

`检查 → 先写 addressMinted=true → _safeMint` → 二次 mint 失败 → `balanceOf == 1`
