Teaching reentry · ReenteringReceiver

Callback body reenters mint. With Vulnerable you can get multiple in one tx; with Fixed the second call fails. Maps to HypeBearsCallbackStudent in-repo.

function onERC721Received(...)
  external returns (bytes4)
{
  nfts += 1;
  if (!target.minted(address(this))) {
    try target.mintNFT() {} catch {}
  }
  return IERC721Receiver
    .onERC721Received.selector;
}
